📖 Print guide — mm accuracy

  1. Generate preview, then Print.
  2. In the Chrome dialog set: Margins None, Scale 100% (never "Fit to page"), ☑ Background graphics.
  3. Paper: A4 for Avery/Mini sheets; roll width (e.g. 54mm) for Dymo; 102×152mm for 4×6".
  4. First time: print Calibration page and measure the 100mm ruler with a real ruler.

Laser/Inkjet (A4): A4 in tray, correct template. Dashed borders are screen-only, never printed.
Thermal (roll): Mode Roll, paper = roll width. Skips a label? Raise SensGap by 1–2mm.
